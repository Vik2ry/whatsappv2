# Whatsapp 2.0

React.js and Next.js project by [**Sonny Sangha**](https://www.youtube.com/channel/UCqeTj_QAnNlmt7FwzNwHZnA) on YouTube

This is a learning project to improve React.js and Next.js knowledge

YouTube Video: [🔴 Let's build Whatsapp 2.0 with NEXT.JS! (1-1 Messaging, Live Status, Styled-Components, React.JS)](https://youtu.be/svlEVg0To_c)

## Product questions

### Who uses it?
Developers learning React and Next.js. For a user it is a WhatsApp Web look-alike where signed-in people chat one-to-one.

### What problem does it solve?
It teaches real-time messaging with Firebase: Google sign-in, live chat updates, chat lists and a styled-components UI. It follows Sonny Sangha's tutorial.

### Why would someone pay for it?
They wouldn't. It is a learning project. Messaging apps earn money from scale, end-to-end security and business tools, none of which this clone attempts.
